# 設計

* Rust での実装を第一候補とする。
* デバイスアクセス等、Rust での実装が存在しない場合は C言語 を利用する。

## 構成の考え方

実機でしか確かめられない部分と、机上で確かめられる部分を分ける。

* `m5a-core` — ハードウェアに触れないロジック。設定、状態遷移、ガードレール、
  Realtime プロトコル、音声変換、表情、描画。ホストで単体テストする
* `m5a` — 実機に触れる層。Espressif 公式の CoreS3 向け BSP
  （`espressif/m5stack_core_s3`）と LVGL を呼び出し、コア層が定めた
  トレイトを実装して差し込む

コア層は ESP-IDF に一切依存しない。これにより μ-law 変換や状態遷移のような
間違えやすい部分を、実機なしで網羅的に検証できる。顔についても「どこに何を
どの色で置くか」はコア層で決めてテストし、画素を塗るのは LVGL に任せる。

電源IC・画面・タッチ・SDカードの初期化は BSP に任せる。自前で書くと
レジスタ列や端子の取り合いを取り違えやすく、実機でしか気づけないため。
