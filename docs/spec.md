# 仕様

## 概要

M5Stack CoreS3（ESP32-S3）上で動作する、子供向けの音声対話アシスタント。
ボタンを押しながら話しかけると、画面のアシスタントの顔が表情で反応しながら
音声で応答する。

## 対象ユーザー

* 5歳児
* 文字が読めないことを前提とし、操作は画面のボタンひとつと音声だけで完結させる
* セットアップは親が行う

## 機能要件

### 初回セットアップ

* セットアップは親が行う。本体上での対話的な設定操作は行わない
* 起動時に SD カードへ設定ファイルが無ければ、記入例つきの雛形を作って保存する
* 親は SD カードを PC に挿し、テキストエディタで雛形を編集する
  * 子どもの名前
  * Wi-Fi 設定（SSID／パスワード）
  * OpenAI APIキー
* 記入済みの SD カードを戻して起動すると、以降は保存された設定で動作する

詳細は [初回セットアップ](spec/setup.md) に記述する。

### 音声入力

* 画面右下に「おはなしボタン」を表示する
* ボタンを**押している間だけ**録音する。離すと送信し、応答を求める
* 応答中にボタンを押したら、応答を打ち切って聞く側に回る

### アシスタントの顔表示

* 画面にアシスタントの顔を表示し、状態に応じて表情をアニメーション表示する
* 顔は画像ファイルではなく図形の組み合わせで描く

詳細は [顔と画面](spec/face.md) に記述する。

### 音声対話

* OpenAI Realtime API（モデル `gpt-realtime-2.1-mini`）を用いて音声で対話する
* 音声は既定で G.711 μ-law でやりとりする。設定で PCM に切り替えられる
* アシスタントは対話の中で子どもの名前を呼びかける

詳細は [音声対話](spec/conversation.md) に記述する。

### web検索

* モデルが知らないこと・最新のできごとを尋ねられたら、function calling で
  web検索（Tavily）を呼び出して調べる
* 検索は `config.toml` に検索用の APIキーを記入した場合だけ有効になる。
  未記入なら検索の機能そのものを使わず、モデルは知っている範囲でだけ答える
* 検索できなかった・結果が得られなかったときは「わからない」に倒し、
  応答を待たせたままにしない

詳細は [音声対話](spec/conversation.md) に記述する。

### 設定・認証情報の管理

* 設定と APIキーは SD カード上の `/.m5a/config.toml`（TOML 形式）に置く

### 会話ログ

* 文字起こしを `/.m5a/logs/` に日付ごとのテキストファイルとして残す
* 音声そのものは保存しない

### ガードレール

* セッションへの指示文で、5歳児向けの話し方と禁止事項を定める
* あわせて端末内で文字起こしを検査し、危険な話題を安全な言葉に差し替える

詳細は [ガードレール](spec/guardrail.md) に記述する。

### 画面に出す文字

* 通常の対話中は文字を出さず、顔とボタンだけで伝える
* 設定不備・Wi-Fi失敗など**親に対処してもらう必要がある場合のみ**日本語を表示する

## 実装の段階

1. **第1段階**（実機で確認済み）— 設定の読み書き、状態遷移、ガードレール、
   Realtime プロトコル、表情と配置をロジックとして完成させ、実機で
   電源投入・SDカード・画面・タッチまで動かす
2. **第2段階**（実機で確認済み）— Wi-Fi 接続、Realtime API との対話、
   音声の入出力まで通しで動作する

## 未確定の項目

* 日本語の画面表示に使う字体（LVGL のフォント変換で作る）
* 音声の遅延と通話品質の実測にもとづく音声形式の既定値の見直し
* Wi-Fi 未接続時に子どもへ何を見せるか
