# ガードレール

二段構えにする。主たる制御はセッションへの指示文で行い、端末内の語句検査は
指示文が効かなかったときの受け皿として置く。

## 指示文

セッション確立時に次の内容を渡す。

* 設定ファイルで決めたアシスタント自身の名前を伝え、名前を聞かれたら
  その名前で答えるようにする（[初回セットアップ](setup.md)参照）
* 5歳の子どもの友だちとして、ひらがな中心のやさしい言葉で話す
* 一度の返事は100文字程度まで
* 名前を呼びかけるのは話の最初か特別なときだけにする
* ゆっくり、はっきり、落ち着いた声で話す
* 危ないことはダメだが、世の中は厳しいので優しいだけの回答をしない。
  体を鍛える話題には少し厳しめに、継続の必要性とモチベーションを
  高める方法を伝える
* 怖い話、暴力、性的な話をしない
* 人を傷つける言葉を使わない
* 知らないことは正直に「わからない」と言う
* 悲しそうなときは気持ちを受け止め、家の人に話すよう勧める

## 端末内の語句検査

文字起こしに対して、明らかに危険な語だけを調べる。

| 分類 | 扱い |
|---|---|
| 性的な内容 | 別の話題に促す言葉に差し替える |
| 加害の方法 | 別の話題に促す言葉に差し替える |
| 自分を傷つけたい気持ち | 気持ちを受け止め、家の人に話すよう促す。**親への記録を残す** |

語彙をあえて狭く保っている。5歳児の素朴な質問（死や病気への疑問など）まで
遮ってしまうと、かえって子どもの信頼を損なうため。身体の部位名のように
子どもが普通に使う言葉も対象にしない。

自分を傷つけたい気持ちを示す言葉は、遮断ではなく**受け止めたうえで大人に
つなぐ**扱いにする。見落としが最も惜しいため、他の分類より先に調べる。

## web検索の結果

検索結果はインターネット由来で内容を事前に検査できないため、そのまま読み
上げさせず、セッションの指示文（怖い話・暴力・性的な話をしない等）の制約
の中で応答を組み立てさせる。検索が使えない・失敗した・結果が得られない
ときは「わからない」に倒し、作り話をさせない。
