# 顔と画面

画面は 320×240。顔は画像ファイルを持たず、円・楕円・矩形・線で描く。
読み込み待ちが無く、まばたきや口の動きを滑らかに変えられるため。

画面はこの「アシスタント画面」と、[設定画面](settings.md)の2つを持ち、
左右スワイプで切り替えられる。起動時・設定不備・失敗時は自動的に
設定画面へ切り替わるため、Trouble表情は設定画面が出るまでの一瞬しか
目にしない（詳細は [状態遷移](../design/state.md) を参照）。

## 表情

| 状態 | 表情 | 見た目 |
|---|---|---|
| 起動直後・接続中 | Waiting | 顔は出さず、画面中央でスピナーを回す |
| 待機中 | Idle | 目を開けて笑っている |
| 録音中 | Listening | 目（白目・瞳とも）を大きくして見開く |
| 応答待ち | Thinking | 視線が左右に泳ぐ |
| 応答再生中 | Talking | 声の大きさに合わせて口が動く |
| 設定不備・失敗 | Trouble | 眉が下がり、背景が赤みを帯びる |

## 動き

* **目の形** — まばたきしていない間は常に真円で描く。表情ごとの開き具合
  （Trouble は細め、Listening は全開、など）は幅と高さへ同じ比率で掛かる。
  まばたきだけは高さにのみ重ねて掛かり、幅は変えない。目を細めるように
  まぶたが閉じる自然な見た目になる
* **まばたき** — 2.5〜5秒の間隔で 140ms かけて閉じて開く。間隔は一定にすると
  機械的に見えるため散らす。眠っている顔はまばたきしない
* **口** — 応答再生中のみ、再生している音声の大きさに追従する
* **視線** — 応答待ちのときだけ左右にゆっくり往復する

### 待機中のバリエーション

待機中がずっと同じ動きだと機械的に見えるため、次の2つをときどき挟む。
どれも待機中（Idle）のときだけ起こる。

* **流し目** — 数秒おきに、視線を左・右・上・下のどれかへ動かしてしばらく
  留め、また正面へ戻す。正面から向きへは100msで移り、その向きを
  800〜2,800msの範囲でランダムに保ち、また100msで正面へ戻る。
  留める長さを一定にすると機械的に見えるため散らす。瞬間的に切り替わらず、
  途中の向きを経てなめらかに動く
* **二連続まばたき** — まばたきのあと、ある確率でもう一度すぐにまばたきする

### 聞いているときのうなずき

子どもの声を検出した瞬間に、目（白目と瞳をまとめて）を軽く下げて
うなずくように動かす。約100msで下を向き、約100msで正面へ戻る。これを
1回、またはある確率で2回連続で行う。聞いていることが伝わるよう、
録音中は目そのものも普段より大きくして見開いている。

## 立ち上げ中の見せ方

起動から接続までは顔を出さず、スピナーだけを見せる。

Wi-Fi は最初の数回つながらないことが普通にある。そのたびに困り顔を見せると
子どもが不安になるため、**失敗が5回続くまでは読み込み中として扱う**。
それでも駄目なときだけ困り顔にして親に伝える。

設定不備は親が直すまで直らないので、こちらは最初から困り顔で見せる。

## おはなしボタン

画面右下にマイクの絵を表示する。押している間だけ録音する。

| 状態 | 色 |
|---|---|
| 待機中・応答中 | 緑（押せる） |
| 録音中 | 橙（録音していることが分かる） |
| 接続中・失敗中 | くすんだ色（押しても始まらない） |

**押せる場所は画面全体**にする。5歳児は小さな的を正確に狙えない。
マイクの絵は「ここを押すと話せる」と伝える目印であり、押せる場所を
限る枠ではない。
