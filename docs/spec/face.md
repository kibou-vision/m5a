# 顔と画面

画面は 320×240。顔は画像ファイルを持たず、円・楕円・矩形・線で描く。
読み込み待ちが無く、まばたきや口の動きを滑らかに変えられるため。

## 表情

| 状態 | 表情 | 見た目 |
|---|---|---|
| 起動直後・接続中 | Waiting | 顔は出さず、画面中央でスピナーを回す |
| 待機中 | Idle | 目を開けて笑っている |
| 録音中 | Listening | 目を大きく開ける |
| 応答待ち | Thinking | 視線が左右に泳ぐ |
| 応答再生中 | Talking | 声の大きさに合わせて口が動く |
| 設定不備・失敗 | Trouble | 眉が下がり、背景が赤みを帯びる |

## 動き

* **まばたき** — 2.5〜5秒の間隔で 140ms かけて閉じて開く。間隔は一定にすると
  機械的に見えるため散らす。眠っている顔はまばたきしない
* **口** — 応答再生中のみ、再生している音声の大きさに追従する
* **視線** — 応答待ちのときだけ左右にゆっくり往復する

## 立ち上げ中の見せ方

起動から接続までは顔を出さず、スピナーだけを見せる。

Wi-Fi は最初の数回つながらないことが普通にある。そのたびに困り顔を見せると
子どもが不安になるため、**失敗が5回続くまでは読み込み中として扱う**。
それでも駄目なときだけ困り顔にして親に伝える。

設定不備は親が直すまで直らないので、こちらは最初から困り顔で見せる。

## おはなしボタン

画面右下にマイクの絵を表示する。押している間だけ録音する。

| 状態 | 色 |
|---|---|
| 待機中・応答中 | 緑（押せる） |
| 録音中 | 橙（録音していることが分かる） |
| 接続中・失敗中 | くすんだ色（押しても始まらない） |

**押せる場所は画面全体**にする。5歳児は小さな的を正確に狙えない。
マイクの絵は「ここを押すと話せる」と伝える目印であり、押せる場所を
限る枠ではない。
