# 設定画面

各モジュール（画面・SDカード・マイク・スピーカー・WiFi・話す相手・
インターネット検索）の準備状況を一覧で見せる画面。アシスタント画面
（[顔と画面](face.md)）とは別の画面として持ち、左右スワイプで手動でも
切り替えられる。

## いつ出るか

* 起動直後は必ずこの画面から見せる。画面が使えるようになった時点で
  まず一度描き、SDカードのマウントなど時間のかかる処理を待たずに
  できるだけ早く映す
* 設定不備（`AppState::SetupRequired`）や失敗からの復帰待ち
  （`AppState::Recovering`）に入った瞬間、アシスタント画面を見ていても
  問答無用でこの画面に切り替わる
* 監視対象の全モジュールが「Ready」になったら、自動的に
  アシスタント画面へ戻る

## 画面の文字は英語の短い単語のみ

実機に日本語フォントを組み込んでいないため、設定画面の文字は英語のみ。
さらに5歳児向けの画面に長い英文は不要なため、モジュールの状態は
`Ready` / `Checking...` / `Failed` の3種類の短い単語だけで表す。
何が起きてどう直すかの詳しい理由は画面には出さず、シリアルログにだけ
残す。会話ログ（`/.m5a/logs/`）やシリアルログは引き続き日本語のまま残す。

WiFi・話す相手は失敗しても自動でやり直し続けるため、`Failed` にはせず
`Checking...` のまま留める。ここで `Failed` を出すと、やり直すたびに
点滅して見え、実際には直ろうとしているのに壊れたままに見えてしまう。
自動でやり直す仕組みが無いマイク・SDカードは、失敗したら素直に
`Failed` にする。

## モジュール一覧

上から順に、縦一列でアイコンとステータスを並べる。アイコンだけで
どのモジュールかが伝わるため、モジュール名の文字は表示しない。

| モジュール | アイコン | 備考 |
|---|---|---|
| 画面 | 画像 | 描画できている時点で動いているとみなし、常に「Ready」 |
| SDカード | SDカード | 起動時のマウント・設定読み込みと、会話ログの書き込み失敗を見る |
| マイク | オーディオ | 起動時の初期化結果を見る。準備できたら感度調整スライダーに変わる |
| スピーカー | 音量 | マイクと同じ初期化結果を見る。準備できたら音量調整スライダーに変わる |
| WiFi | WiFi | 接続の成否を見る |
| 話す相手 | 通話 | OpenAI Realtime API とのセッション確立を見る |
| インターネット検索 | 検索(GPS) | `config.toml` に検索用APIキーがあるときだけ一覧に出す |

各行はアイコンの横に状態文（`Ready` / `Checking...` / `Failed`）を
表示し、右端に確認中／OK／警告の小さな印を重ねる。アイコンは既定の
文字サイズより一回り大きく表示する。マイク・スピーカーの行だけは、
`Ready` になった瞬間に状態文の位置がスライダーに置き換わる
（[スピーカー音量・マイク感度の調整](#スピーカー音量マイク感度の調整)参照）。
右端の確認中／OK／警告の印はスライダーになっても出したままにする。

## 声の種類の選択

唯一、画面上で完結して変更できる設定項目。「話す相手」の準備ができると、
スピーカーの行に音量スライダーと並んでコンボボックスが現れ、声の一覧
（`marin` / `cedar` など）から選べる。選ぶと：

1. その場で選択状態が変わる
2. `/.m5a/config.toml` の `[openai] voice` に書き戻される（他の項目や
   コメントはそのまま残す）
3. すでに確立している対話セッションには即座には反映されない
   （OpenAI Realtime API はセッション確立後に声を変えられない）。
   次にセッションを開くとき（次回起動、または再接続時）から使われる

WiFi の SSID・パスワードや OpenAI の APIキーのように、SDカード上の
`config.toml` を親がテキストエディタで書き込む項目は、この画面では
ステータス表示のみとし、画面上から変更する手段は持たない。

## スピーカー音量・マイク感度の調整

声の種類の選択とならぶ、画面上で完結して変更できる設定項目。マイク・
スピーカーの行がそれぞれ「Ready」になると、状態文の位置にスライダーが
現れる。

* スピーカーは音量（0〜100%）、マイクは感度（0〜42dB）をスライダーで変える
* ドラッグ中はすぐに実際の音量・感度へ反映され、指を離すとその値が
  `/.m5a/config.toml` の `[audio]` セクションへ書き戻される（他の項目や
  コメントはそのまま残す）
* 声の種類とは異なり、確立済みの対話セッション中でもその場で効く
  （音量・感度はハードウェア側の設定で、Realtime API のセッションとは
  無関係なため）
* 次回起動時は、保存した値がそのまま初期値になる

## 閉じるボタン

画面右上に、アシスタント画面へ戻るための閉じるボタン（✕）を常に置く。
タップすると、左から右へのスワイプと同じくアシスタント画面へ戻る。
スワイプに気づかない親でも迷わず閉じられるようにするための、
もう一つの手段。

## スワイプ

画面を左右にドラッグすると手動で切り替えられる。右から左へのスワイプで
設定画面へ、左から右へのスワイプでアシスタント画面へ戻る
（`core::gesture::detect_swipe`）。閾値未満の動きや、縦方向の動きが
大きい斜めの操作はスワイプとみなさない。**指を離すのを待たず、動いた
時点でスワイプと分かり次第すぐに切り替える**。アシスタント画面は
画面全体が「おはなしボタン」を兼ねているため、離すまで待つと録音が
始まったまま切り替わらないように見えるため。

設定画面を見ている間は、おはなしボタン（画面全体タップでの録音開始）は
無効にする。

親がスワイプで自分から設定画面を開いたときは、全モジュールが揃って
いても自動でアシスタント画面へ押し戻さない。開いた直後に押し戻されて
操作できないことを避けるため。設定不備や失敗（[いつ出るか](#いつ出るか)
参照）で改めて設定画面に切り替わったときは、直せば自動で戻る通常の
挙動に戻る。
